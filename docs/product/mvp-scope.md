# MVP Scope

## Objective

Validate that users value a focused, trustworthy browser tool for preparing ecommerce images.

## MVP product

The first shipped product should be one excellent standalone tool: **Image Optimizer**.

The repository and interface may acknowledge future tools, but unfinished tools must not distract from the working one.

## Image Optimizer capabilities

### Required

- Upload one or multiple supported images
- Drag and drop
- Clear processing state
- Choose a simple quality or compression level
- Preview original and output information
- Show file-size reduction
- Process each image reliably
- Download one image
- Download all results as a ZIP
- Work on mobile and desktop
- Explain privacy and processing behavior
- Handle unsupported or broken files clearly

### Desirable if low-risk

- Clipboard paste
- Preserve or remove metadata option
- Basic output-format choice
- Persistent last-used settings
- Estimated output before processing

## Explicitly out of MVP

- User accounts
- Cloud projects
- Payments
- Team collaboration
- AI image generation
- Background removal
- API access
- Plugin ecosystem
- Automated marketplace publishing
- Full connected multi-step workflow
- Native mobile application

## MVP validation questions

- Can users understand the tool without instructions?
- Is output quality acceptable at useful file-size reductions?
- Does batch processing remain responsive?
- Can users confidently identify and download outputs?
- Do users request presets, workflows, or saved settings after using the standalone tool?
